# 局限

把做不到的事写清楚，和把做到的事写清楚一样重要。

## 三条主要边界

1. **它不是身份判断** — NSCHA 不识别「你是不是人」，只让批量请求变贵。由真人逐个操作的打码农场依然可以完成验证，只是每一次都要付同样的计算成本。
2. **无状态是一种取舍** — 兑换记录保存在进程内，多实例之间并不共享。兑换令牌在其有效期内也不做全局一次性消费；真正的保证来自短时效、用途绑定与签名。
3. **依赖真实浏览器能力** — 求解在 Web Worker 与 WebAssembly 中进行。缺少这些能力的环境会收到明确的错误提示，而不是被静默放行。
