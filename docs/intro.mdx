# NSCHA 是什么

<div className="nscha-latin">Non-Surveillance CAPTCHA for Human Authentication</div>

<div className="nscha-lede">不观察你，也不打扰你 —— 只让每一次提交付出一点计算成本。</div>

NSCHA 是我们的人机验证产品。它**不试图判断屏幕前是不是真人**，而是把「提交」这件事标上一个极小的价格：普通访客只花几十毫秒的 CPU，批量刷接口的人却要为每一次请求重复付账。

验证全过程只发生在访客的浏览器与本站服务器之间。挑战由本站签发、求解器由本站提供、令牌由本站校验 —— 没有外部域名、没有 Cookie、没有行为采集，也没有需要辨认的交通灯。

## 三个设计取舍

<div className="nscha-cards">
  <div className="nscha-card">
    <div className="n">01 / SAME ORIGIN</div>
    <h3>同源闭环</h3>
    <p>挑战、求解器与校验接口都在本站域名下，验证过程不产生任何第三方请求。</p>
  </div>
  <div className="nscha-card">
    <div className="n">02 / NO IDENTIFIER</div>
    <h3>零持久标识</h3>
    <p>不写 Cookie、不做指纹、不记录鼠标轨迹。验证结束，这次访问就结束。</p>
  </div>
  <div className="nscha-card">
    <div className="n">03 / NO PUZZLE</div>
    <h3>没有谜题</h3>
    <p>访客只需等待一次后台计算，不需要选图、识字，也不用在九宫格里找东西。</p>
  </div>
</div>
