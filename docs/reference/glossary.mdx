# 术语表

| 术语 | 含义 |
| --- | --- |
| **NSCHA** | Non-Surveillance CAPTCHA for Human Authentication，本站描述的产品 |
| **挑战（challenge）** | 服务端签发的参数集合 `c / s / d` 与带签名的令牌 |
| **子挑战** | 一道独立的小计算题；一次验证包含 `c` 道 |
| **盐（salt）** | 由挑战令牌与子挑战序号派生的输入前缀，长度为 `s` |
| **难度（difficulty）** | 目标哈希前导零个数 `d`，每 +1 期望尝试约 ×16 |
| **解（solution）** | 命中难度要求的计数器值，随序号一起交给兑换接口 |
| **兑换（redeem）** | 交回解、验签验算、签发兑换令牌的动作；一次性指这一步 |
| **兑换令牌** | 短时效、绑定用途、带专用标记的字符串，随表单提交 |
| **用途 / scope** | `login` / `register` / `reset` 之一，绑定表单与令牌 |
| **专用标记** | 令牌内用于区别「验证令牌」与「会话令牌」的字段 |
| **占位记录** | 进程内同步的「不存在才写入」记录，阻止重复兑换 |
| **同源** | 挑战、求解器、校验接口都在本站域名下，无第三方请求 |
| **零持久标识** | 不写 Cookie、不做指纹、不建立可跨访问关联的主键 |

:::tip

想看这些概念怎么串起来，从[工作原理](../how-it-works.mdx)读起。

:::
