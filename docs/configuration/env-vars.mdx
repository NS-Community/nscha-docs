# 环境变量

## 签名

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| `CAP_SECRET` | 无（必填） | HS256 挑战签名密钥。用长随机串；轮换会让在途挑战全部失效 |
| `CAP_TOKEN_SECRET` | 同 `CAP_SECRET` | 兑换令牌签名密钥。若业务系统也用 JWT，建议单独设一把 |

```bash
node -e "console.log(require('crypto').randomBytes(48).toString('hex'))"
```

## 难度

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| `CAP_CHALLENGE_COUNT` | `20` | 子挑战数量，越大客户端总计算量越大 |
| `CAP_CHALLENGE_SIZE` | `32` | 每个子挑战的盐长度（字节） |
| `CAP_CHALLENGE_DIFFICULTY` | `3` | 目标哈希前导零个数，每 +1 期望尝试次数约 ×16 |

## 时效

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| `CAP_EXPIRES_SECONDS` | `600` | 挑战令牌有效期 |
| `CAP_TOKEN_TTL_SECONDS` | `1200` | 兑换令牌有效期 |

两个时钟要匹配用户填写表单的节奏：挑战太短会让慢网络用户还没提交就过期；令牌太长会放大重放窗口。

## 资源

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| `CAP_ASSET_BASE` | `/cap` | 求解器与兜底资源的静态目录。保持相对路径以维持同源 |

## 用途与来源

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| `CAP_SCOPES` | `login,register,reset` | 用途白名单，逗号分隔小写。新增表单先登记 |
| `ALLOWED_ORIGIN` | `*` | 允许嵌入的站点来源，逗号分隔 |
| `NSCHA_LABEL` / `NSCHA_LINK` | `NSCHA` / 文档站 | 盒子上的品牌文案与链接 |

:::caution

`ALLOWED_ORIGIN` 默认 `*` 是为了让任何人都能先试起来。生产环境不收敛，别人可以白用你的算力。

:::

:::info

**生效时机** — 这些值在进程启动时读取。修改后必须重启服务；只刷新浏览器不会生效。

:::

:::caution

开发环境里常见的「改了配置却没变化」，几乎都是因为服务进程没重启。

:::
