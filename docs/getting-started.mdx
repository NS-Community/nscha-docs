# 入门指南

这一章把一次完整接入拆成三个动作：**准备环境 → 表单挂组件 → 服务端校验令牌**。

## 前置条件

- 一个可运行的服务端进程（用于签发挑战、兑换与校验）
- 一个设置了 `CAP_SECRET` 的环境
- 静态资源目录 `/cap/` 可从同源访问

:::caution

`CAP_SECRET` 是挑战签名密钥。生产环境必须换成长随机串，且不要复用开发值。轮换它会让所有在途挑战立即失效。

:::
